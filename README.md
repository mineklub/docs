# MineCore docs

Dansk dokumentation til [MineCore](https://github.com/mineklub/minecore), MineKlubs Paper-plugin til betalinger og votes.

## Lokal udvikling

```bash
npm install
npm run start
```

Byg sitet statisk med `npm run build`, eller se det byggede site med `npm run preview`.

## Indhold

- [Kom i gang](https://docs.mineclub.dk/docs/kom-i-gang)
- [Installation](https://docs.mineclub.dk/docs/installation)
- [API-reference](https://docs.mineclub.dk/docs/api)
- [Skript-hooks](https://docs.mineclub.dk/docs/skript)

Dokumentationen er skrevet på dansk. Kode-, klasse- og API-navne følger MineCore-kildekoden.
